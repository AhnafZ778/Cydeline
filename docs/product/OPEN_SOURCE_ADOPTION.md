# Open-source adoption record

23 October 2026 recovery decision: introduce no new runtime framework. Retain the project's existing attacker, target adapter, control plane, authored scenarios and server scoring.

The supplied plan proposes studying [Strix](https://github.com/usestrix/strix) for validated execution feedback, [KC7](https://github.com/KC7-Foundation/kc7) for investigation teaching, and later [CALDERA](https://github.com/apache/caldera), [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team), [Adversary Emulation Library](https://github.com/center-for-threat-informed-defense/adversary_emulation_library), [Attack Flow](https://github.com/center-for-threat-informed-defense/attack-flow) and [Sigma](https://github.com/SigmaHQ/sigma).

No source code, scenario, asset, rule or new dependency from those projects was copied during this increment. Versions and licenses have not been independently reinspected during recovery; the supplied license assessments are research input, not permission to copy arbitrary hosted material. Any future reuse must pin the inspected commit/version, actual license scope, attribution, dependencies and maintenance/security considerations in this file and `docs/provenance/THIRD_PARTY.md`.

CyberBattleSim and DetectionLab remain outside this increment as specified in the accepted plan. Existing dependencies are unchanged. License and maintenance claims must be freshly verified before adoption.
