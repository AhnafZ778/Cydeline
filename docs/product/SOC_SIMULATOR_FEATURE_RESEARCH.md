# SOC simulator feature research — 23 October 2026

Prepared for Ahnaf / Cydeline. Public-source market sweep, not authenticated hands-on certification of every platform. No finite public search establishes coverage of every private, newly launched, or inaccessible offering. Product families, separate simulator modes, and infrastructure foundations are distinguished below; LetsDefend belongs to HTB and RangeForce belongs to Cyberbit.

## Interpretation

Documented means described in primary vendor/upstream documentation, not independently reproduced. User feedback is sampled and self-selected; many G2 reviews are older or incentivized, and vendor case studies are selected testimonials. An advantage/recommendation is an inference, not proof of market share, causal ROI, educational transfer or customer consensus. A browser VM does not prove an autonomous live attack; AI tutoring/grading/scenario generation, scripted conditional emulation, and an AI making state-dependent target actions are different capabilities.

## Recommended implementation sequence (proposal, not approved scope expansion)

1. Finish Saad S2/S3/S4 and connect Tanvir choose_action: target-backed actions, audit correlation, idempotent containment, real verification, authoritative score and replay. Preserve Ahnaf’s existing shell.
2. Add a hybrid analyst workspace: existing SOC console plus a launched tool-equipped workstation and direct web links to one real SIEM/DFIR service. A provisioning worker creates isolated run-scoped targets; a browser gateway supplies desktop access. For the small application target, an extra VM is not required merely to claim live behavior.
3. Generate benign users as actual target workflow requests and measure continuity; avoid teaching that every denied request or command-line user agent is malicious.
4. Add reviewed state-dependent branches and same-state/same-role AI-versus-policy tests before expanding model size. Keep hidden state and execution permission server-side.
5. Add learner-authored timeline, deterministic evidence-linked grading, optional coach, durable resume and fault recovery. Separate learning hints, operational timers and infrastructure latency.
6. Pilot instructor assignments and cohort reports; then add role handoffs, business-message injects and scenario blueprint authoring as demand warrants.

## Browser VM integration proposal

The remote machine runs on server infrastructure. The browser displays a streamed desktop or accesses a web application; it does not itself host the VM. Add an authorized console-session endpoint under the control plane, a run-to-target inventory, an independent provisioning worker, and a gateway such as Guacamole (RDP/VNC/SSH) or an appropriately isolated workspace service. React receives a short-lived connection reference rather than hypervisor credentials. Keep web-tool reverse proxy links separate from desktop consoles. Expose pending/ready/failed status, reconnect, fullscreen, controlled clipboard and session expiry. Use separate per-run networks, measured target checks and resource caps; revoke console access when a run is destroyed. Snapshot rollback or a browser reconnect is not itself proof that old authentication handles have been invalidated.

Transport options are a proposed implementation based on upstream docs, not reverse-engineered claims about proprietary competitors. Ludus/Proxmox is a possible later VM substrate; container workspaces may be lighter for Linux tool desktops, while Windows/AD fidelity requires suitable VM/licensing choices. Benchmark actual hardware before committing to deployment size or per-user cost.

## AI competitor finding

CybExer’s armasuisse case study is a close match to the remembered unfinished project: it explicitly distinguishes available AI exercise scoring from AI adversary and defensive-support capabilities still being developed. HTB’s AI Range Enterprise Edition was announced on October 6, 2026 for agent appraisal and human operator competence, so AI-enabled ranges are already commercial adjacent offerings. Neither announcement alone proves that a particular trainee product offers an unscripted LLM continuously replanning attacks in response to measured human containment. CYBER RANGES documents conditional reactions in its attack scripts; Reflex describes adaptive crisis role-play. Avoid claiming Cydeline is the first AI range or that all competitors only replay fixed logs.

## Evidence gaps / useful recordings

- HTB Threat Range and AI Range: complete participant run, host/tool launch, containment and next attacker action, final report and administrator analytics; current source documents roles and evaluation well, but attacker planning internals remain unclear.
- Immersive Dynamic Threat Ranges, Cyberbit and SimSpace: full live run with network/tool access and a response that changes subsequent attack behavior, plus instructor view. Immersive DTR introduction was login-gated; builder docs and product releases were accessible.
- Circadence Project Ares GEN3 / RangeGPT: distinguish coach, environment generation, attack bots and genuinely adaptive attacker decisions in a current version.
- CybExer AI project: only a development/pilot demonstration can substantiate behavior beyond the published project description.
- Emerging Corevex/CyberTwinX/SOCSimulator/NightRange: authenticated walkthrough and real execution evidence before assigning market-success or autonomy claims; NightRange defensive mode is described as coming to beta.

For any recording, capture launch → investigation → action → subsequent target/attacker response → debrief → reset, and the instructor view where accessible; omit credentials and private tenant information. A video establishes observable behavior, while architecture claims still need docs or code.
